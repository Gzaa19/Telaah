# Project

## Telaah - AI Scientific Journal Paper & Manuscript Generator

**AI Engineer | Python, FastAPI, PostgreSQL, Google Drive API, Hugging Face, Next.js**

- Built a research platform that helps students and researchers organize literature and prepare scientific papers.
- Created a document import feature for PDF and DOCX files from Google Drive, including file search, text extraction, and progress tracking.
- Developed a document processing system that divides long documents into **1,200-character** sections with **150-character** overlap, using batches of **32**.
- Added secure Google login, researcher-specific document access, document search, and automatic retry handling for up to **3 attempts**.

**Technology:** Python, FastAPI, PostgreSQL, pgvector, Google OAuth 2.0, Google Drive API, Hugging Face, Sentence Transformers, ARQ, Next.js.
